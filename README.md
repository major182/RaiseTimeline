# タイムライン型 SNS（RaiseTimeline）

## はじめに

- 本リポジトリは、スクールの課題として major182 が作ったタイムライン型 SNS の Web アプリ「RaiseTimeline」に関するものです
- 課題の終了に伴い AWS の環境を削除しているため、現在はご利用いただけません（[利用方法](#利用方法)）

## コンセプト

- インプレッション数（表示回数）やリツイートは、数字を追いかける使い方や、意図しない拡散を生みやすいと考え、「フォローしている人の投稿を穏やかに読み書きできる SNS」を目指しました
- 要件定義・設計・実装・テスト・デプロイまでを1人で行いました

## アプリ概要

- X（旧 Twitter）のように、テキストと画像を投稿して読み合うタイムライン型の SNS です
- インプレッション数は表示も記録もせず、リツイート・引用の機能もありません。いいねとコメントの数は表示します
- 主な機能は次のとおりです
  - ログイン
  - タイムライン（「全体」と「フォロー中」のタブ。フォロー中の人がいいねした投稿、留守中のハイライト）
  - 投稿（テキスト・画像）
  - コメントと返信、メンション（`@ユーザー名`）
  - いいね
  - フォロー・フォロワー
  - 利用者の検索
- 機能の詳細は [機能一覧](docs/01-1_feature-list.md) をご覧ください

## 環境

- フロントエンド：React 19.3.0、TypeScript 6.0.3、Vite 8.3.3、Material UI 9.4.0
- バックエンド：Java 25、Spring Boot 4.1.1
- データベース：PostgreSQL 18.6
- インフラ：AWS（CloudFront・S3・ALB・ECS Fargate・RDS・ECR）、Terraform
- CI/CD：GitHub Actions

## 利用方法

- 公開中も、接続できるのは開発者の IP アドレスからだけに制限していました
- また、課題の終了に伴い AWS の環境は削除しており、現在は公開していません
- そのため、一般の方はご利用いただけません。アプリの動きは [デモ動画](#デモ動画) でご覧ください
